# NETBOOST

Plain-language check for any provider.

```powershell
cd NT2
python -m netboost
```

Then open http://127.0.0.1:8765 if the browser does not open by itself.
Python 3.12+ is required. Double-click run-netboost.bat on Windows.

- Check my internet: home side and provider side, in everyday words
- A fix is kept only if the retest is better
- What it means: waiting time, time while downloading, a grade
- Devices: who answered on your network. A speed cap is not offered unless the router accepts one
